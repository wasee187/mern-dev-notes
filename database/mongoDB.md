::: Creating new mongodb project and connect it with nodejs project  
1. Login and go to new project section in mongodb website.   
2. Give the project name, select driver as connection and save the connection link to connect the mongoDB.   
3. Add 0.0.0.0/0 in IP address list to connect from anywhere with the monggoDB.
